# Product Context

## Vision
Jira Notifier is a macOS menu bar app that surfaces Jira Server updates as native macOS notifications. It runs as a lightweight background daemon, keeping developers and product teams aware of issue changes without leaving their workflow. 

## Current Focus
Initial release targeting Jira Server users on macOS — authenticated via macOS Keychain, polling for changes, and dispatching notifications through the Swift menubar app.

## Who It's For
macOS developers and teams using self-hosted Jira Server who want ambient issue awareness without browser tabs.
